# 行程审校与受控重规划

审校结构化行程，返回 PASS、WARN 或 ERROR 问题。该 Skill 的关键规则由 Java 执行器计算，文本判断只用于补充说明。

## 检查顺序

1. 硬约束：目的地和天数完整、每日存在安排、预算不超额、同一景点不重复。
2. 环境约束：雨天户外负载、当前天气使用范围、动态信息核验提示。
3. 常识约束：每天活动数量、抵离日强度、儿童/老人/低体力偏好、机动预算。
4. 对 ERROR 生成定向修正动作；WARN 可保留，但必须在最终成品中披露。
5. 最多允许两轮重规划。两轮后仍有 ERROR 时停止循环，输出失败原因和可执行降级方案。

问题代码、严重级别和修正规则见 [references/review-rules.md](references/review-rules.md)。设计来源见 [references/sources.md](references/sources.md)。

## 输出要求

- 每个问题包含 `code`、`severity`、`day`、`message` 和 `suggestion`。
- 审校通过表示当前结构满足本地规则，不代表票价、营业时间或预约状态已由官方确认。
- 只修正被问题代码影响的部分，保留用户的目的地、天数、预算和兴趣偏好。
