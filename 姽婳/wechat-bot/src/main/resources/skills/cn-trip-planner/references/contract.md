# 行程草案契约

## 输入

- `destination`：当前支持上海、杭州、苏州。
- `days`：1 至 7 天，缺失时默认 3 天。
- `travelers`：1 至 20 人，缺失时默认 2 人。
- `budgetYuan`：总落地预算；缺失时按每人每天 600 元估算。
- `interests`：文化、美食、亲子、自然、夜景、购物等关键词。
- `pace`：relaxed、balanced、packed，默认 balanced。
- `assumptions`：所有推断出的字段必须记录在这里。

## 输出

- 用户收到 Markdown 文件附件，聊天气泡只保留生成完成通知。
- 每日行程：日期序号、主题、时段、活动名称、推荐理由和区域用餐建议。
- 知识块 ID 只保留在内部结构中，不展示给用户。
- 预算：住宿 30%、餐饮 25%、市内交通 20%、门票 15%、机动 10%。
- 天气：当前实况和“不能代表整个行程”的提示。
- 风险：动态信息核验、知识库范围和审校结果集中放在文档末尾。

## 行程密度

- relaxed：每天 1 个核心活动，可加 1 个可选活动。
- balanced：每天 2 个核心活动。
- packed：每天最多 3 个活动；当前微信 Demo 仍建议控制为 2 个以保证可读性。
